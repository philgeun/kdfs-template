# 한국디지털포렌식학회 학술대회 LaTeX 템플릿

이 폴더는 한국디지털포렌식학회가 2026년 하계학술대회 공지에 첨부한 공식 HWP 논문투고양식을 XeLaTeX용으로 재구현한 비공식 LaTeX 템플릿이다.

## 파일

- `kdfs-conference.cls`: 학회 형식을 구현한 문서 클래스
- `main.tex`: 제목, 초록, 표, 그림, 수식, 참고문헌 예제
- `references.bib`: IEEE 순번 인용 예제
- `main.pdf`: 실제 컴파일한 시각 검증본

## 컴파일

Overleaf에서는 Compiler를 `XeLaTeX`로 선택한 뒤 `main.tex`를 컴파일한다. 로컬에서는 다음 중 하나를 사용한다.

```text
tectonic main.tex
latexmk -xelatex main.tex
```

`pdfLaTeX`는 한글 시스템 글꼴을 직접 처리하지 못하므로 지원하지 않는다.

## 확인된 공식 규격

| 항목 | 공식 HWP 기준 | 구현 |
|---|---|---|
| 용지와 좌우 여백 | A4, 좌우 20 mm | `geometry`로 적용 |
| 머리말 | ISSN, JAMS URL, DOI | 모든 페이지에 적용 |
| 한글 제목 | HY견명조 17 pt, 진하게, 자간 8%, 행간 130% | 적용 |
| 영문 제목 | HY견명조 14 pt, 진하게, 자간 0%, 행간 130% | 적용 |
| 국문 및 영문 요약 | 휴먼명조 9 pt, 장평 96%, 자간 8%, 행간 155% | 적용 |
| 주제어 | 국문 및 영문 각각 5개 이내 | 예제에 5개 사용 |
| 본문 | 휴먼명조 10 pt, 자간 0%, 행간 160% | 적용 |
| 장 제목 | 돋움 11 pt, 로마 숫자 | 적용 |
| 절 및 항 제목 | 돋움 10 pt | 적용 |
| 표 | 가운데 배치, 제목은 위쪽, `<Table 1>` 형식 | 적용 |
| 그림 | 가운데 배치, `Figure 1.` 형식 | 적용 |
| 수식 | 9 pt, `(1)` 형식 | 적용 |
| 참고문헌 | IEEE 순번 방식, 모든 항목을 영어로 작성 | `IEEEtran.bst` 사용 |
| 분량 | Full Paper, 참고문헌 포함 6쪽 이상 권장 | 클래스에서 강제하지 않음 |

## 글꼴 대체

공식 HWP는 `HY견명조`, `휴먼명조`, `돋움`을 사용한다. 이 클래스는 해당 글꼴이 설치된 경우 자동으로 사용한다. `휴먼명조` 또는 `돋움`이 없으면 각각 `Noto Serif KR`, `Noto Sans KR`로 대체한다. 대체 글꼴은 줄바꿈과 페이지 수를 바꿀 수 있으므로 최종 제출 전 반드시 PDF를 다시 확인한다.

## 저자 정보 주의

2026년 하계학술대회에 공개된 공식 HWP에는 눈에 보이는 저자 및 소속 블록이 없다. 공지에서는 논문 파일 이메일 제출과 별도의 구글폼 논문 정보 입력을 함께 요구한다. 따라서 이 템플릿은 저자 블록을 임의로 추가하지 않았다. 저자 정보 또는 익명 심사 규칙은 투고 시점의 운영진 안내를 확인한 뒤 적용한다.

## 사용 전 체크리스트

1. `main.tex`의 제목, 국문 및 영문 요약, 주제어를 교체한다.
2. 주제어가 각 언어별 5개 이내인지 확인한다.
3. DOI가 배정되지 않았다면 `XXXXXXXXXXXXXXXXX` 상태를 학회 지침에 따라 처리한다.
4. 참고문헌 항목을 영어로 작성하고 본문 인용 순서를 확인한다.
5. 표, 그림과 수식 번호가 본문 인용과 일치하는지 확인한다.
6. 최종 PDF가 권장 분량과 최신 공지의 제출 조건을 만족하는지 확인한다.
7. 저자 정보, 익명성, 파일명과 제출 경로를 최신 공지에서 다시 확인한다.
